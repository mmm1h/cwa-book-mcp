# 范围与行为

状态：首版需求基线。修改范围以用户后续明确指令为准。

## 目标

多设备上的 Agent 只配置 MCPHub，通过一个书籍服务完成搜索、获取、上传和下载。CWA 保存最终书籍，所有设备从 CWA 获得书籍；本服务仅转发和暂存。

单用户、共享同一书库。第一验收客户端是具备本地文件与 HTTP 能力的 Agent；跨客户端兼容随后验证。

## 需求编号

| 编号 | 要求 |
| --- | --- |
| R01 | 只新增一个服务，MCPHub 统一暴露工具 |
| R02 | 一个 search_books 工具，默认中文优先并尽量复用 CWA |
| R03 | 搜索只返回候选，用户选定后才获取新书 |
| R04 | Z-Library 是首版唯一外部书源；优先复用 heartleo/zlib |
| R05 | 新书在服务端下载、暂存、上传 CWA，不借用发起设备中转 |
| R06 | 本地文件由 Agent 直接上传服务，再提交 CWA，无需用户另行登录 |
| R07 | 可下载书籍必须存在于 CWA，返回临时授权地址供 Agent 保存 |
| R08 | 后台任务持久化，客户端离线或 MCP 会话关闭不取消任务 |
| R09 | CWA 决定转换、入库及重复处理，本服务不改其源码或数据库 |
| R10 | 书库可下载验证通过后才能 ready；上传成功不能直接 ready |
| R11 | 临时网络错误有限重试，认证、验证码、额度和不确定结果有明确状态 |
| R12 | 内存按指定预算验收；文件大小增大不能造成同量级内存增长 |
| R13 | 凭据只在服务端，设备不接触 CWA/Z-Library 凭据 |
| R14 | 计划和文档先行；初始化提交不包含应用实现 |

## 默认搜索顺序

1. 搜索 CWA，优先返回满足查询条件的中文书。
2. 没有合格的 CWA 中文结果时，查询 Z-Library 中文结果。
3. 两边本次查询都确认没有中文结果，再返回 CWA 中的其他语言候选。
4. CWA 其他语言也没有匹配时，返回 Z-Library 其他语言候选。

这意味着 CWA 中只有英文、Z-Library 中有中文时，默认优先展示 Z-Library 中文。中文优先高于“任何本地结果都立即结束”。

- 中文包含简体、繁体；规范化 zh、zh-Hans、zh-Hant、zho、chi、Chinese 等实际源值。
- 缺失语言元数据属于 unknown，不能仅凭书名含中文就认定为中文。
- 用户显式指定语言时遵从该语言，不自动退到其他语言；显式指定 any 则按 CWA → 外部书源。
- 用户只输入书名时，不自行增加作者、译者、年份、格式等硬性筛选条件。
- 作者、格式只有明确传入时才参与过滤。首版不提供译者或版次筛选。
- CWA 不可达时返回错误，不把故障当成无结果而自动下载新书。
- 书源失败或分页未查完时，注明 partial / search_incomplete；不能宣称没有中文。可提供已知其他语言候选，但仍由用户明确选择。
- “无中文”只描述该查询与已完成的有界搜索范围，不代表全站没有该书。

## 获取与复用

获取前再次检查 CWA。若已有足够匹配且可下载的所需格式，直接复用，返回 reused_existing；无需重复下载。

本服务不识别同名作品的不同译本，也不承诺版本隔离。书名、作者、语言和格式是首版匹配依据；ISBN 如可取得可辅助匹配，不能单独当作文件身份。

不主动调用 CWA 删除、合并、覆盖现有格式接口。正常新书上传可能触发 CWA 自己的重复处理，部署验收必须记录相关设置；本项目不提供绕过 CWA 的事务性不覆盖保证。

## 明确不做

- 译本/版次隔离、书名后缀改写、任务标签注入、元数据写回。
- 自建转换引擎、内容提取、OCR、向量检索、NotebookLM 对接。
- 额外书源、书架管理、阅读进度同步、家庭多用户权限。
- Web 管理页面、外部队列/数据库、CLI 转 MCP 中间服务。
- CWA 分叉、镜像内脚本替换、Docker socket 控制、SSH 命令桥接、直接挂载并修改其数据库。
- 下载过程中绕过验证码或自动规避账号限额。
- 首版不实现应用分块、断点续传或并行分片；设备上传未完成时从头重传，已接收的后台任务独立运行。
- 所有客户端都支持电子书聊天附件的假设。没有文件 I/O 的客户端不在首版验收范围。

## 文件和部署边界

由 MCPHub 通过 stdio 的 command/args/env 启动单个 Go 程序，共享一个进程和状态目录。独立 HTTP 运行是可选兼容方式；不要求为本项目另建 Docker 容器。

设备只配置 MCPHub 的工具入口，但实际文件走同一书籍服务的 HTTP 接口。需要沿用现有外网访问方式为该接口提供可达地址。

CWA_BASE_URL 应优先使用服务可达的内网地址。首版设备上传和 CWA 提交都采用完整单请求流式传输；请求大小限制与内存占用是不同问题。部署时按两段通路的实际限制设置允许大小，超过时明确拒绝；HTTP chunked encoding 不能绕过代理限制。
