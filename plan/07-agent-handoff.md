研究中旧的译本隔离建议已经退出首版，不应被重新实现。首版不做分块续传、Range 或等待全部保留格式；以当前契约为准。CWA 源码不得修改。

## 可直接发送的提示词

> 请在这个仓库接手。先读 AGENTS.md 和 plan/README.md，按渐进式导航读取当前阶段所需文档，从最早未完成阶段或指定问题继续，不重复已验证的实现。使用 Go，遵守低内存验收门槛；默认中文优先，所有书籍最终从 CWA 交付。不得修改 CWA 源码，不做译本隔离，不引入 Python 或额外服务。按阶段提交并更新进度。真实接入资料只保存在私有配置中，未取得部署授权时不修改现有环境。

## 接手后第一批动作

- 检查 Git 工作区与当前计划状态，保留其他人的改动。
- 阅读已固定的依赖与验证记录；只在升级或接口变化时重做受影响的实验。
- 从当前阶段继续；原版 CWA 与受控资源测试可通过 acceptance workflow 复现。
- 在任何真实 NAS 写入或配置变更前，核对本轮用户授权范围；本交接文档本身不是生产环境部署授权。
- 把阶段结果、测试和未解决问题写在唯一进度入口，详细证据链接到对应文档。

## 每阶段交付格式

简短说明：完成的行为、验证方法和结果、实际资源数字（若已测）、仍未验证的边界、下一阶段。不要把预计内存、源码推断或模拟结果当成真实服务表现。
